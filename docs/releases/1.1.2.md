# Release 1.1.2

Patch release. Three `phpcbf` fixers changed the meaning of valid code, and a fourth could break closures that include templates. They now fix only what they can fix without changing behaviour. The remaining cases are still reported, but not fixed. See `CHANGELOG.md` for details.

Effective QA matrix: PHP 8.5 with the locked dependency set (PHPCS 3.13.6, Slevomat 8.22.1, WPCS 3.4.1, VIPWPCS 3.1.0, PHPCompatibility 9.3.5). PHP 8.4 is not tested: since 1.1.0 the package requires PHP 8.5. PHPCS 4 is not tested either; it is still experimental.

Upgrade: no ruleset changes are needed. Projects that run `SymPress-WordPress`, `SymPress-Boundary` or `SymPress-Templates` directly must set `testVersion` (see README).
